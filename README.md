# Летающие бегемоты и крокодилы на машинах

Аркада на **J# (Visual J#)** для Visual Studio 2005.
Игрок управляет летающим бегемотом и уворачивается от крокодилов,
которые едут навстречу на красных машинах.

## Требования

- Windows XP / Vista / 7 (J# 2.0 официально работал только там)
- Microsoft Visual Studio 2005
- Установленный **Visual J# 2.0 Redistributable / SDK**
  (входит в VS 2005 при выборе компонента J#)

> Внимание: J# мёртв с 2017 года. Если VS 2005 нет — игру можно
> переписать на C# или Java без потери логики.

## Управление

| Клавиша              | Действие                          |
|----------------------|-----------------------------------|
| Пробел               | Подбросить бегемота вверх         |
| Стрелка вверх (↑)    | То же самое                        |
| Отпустить клавишу    | Бегемот начинает падать           |
| Пробел (после конца) | Начать игру заново                |

## Правила

- Бегемот постоянно падает (гравитация `0.5`)
- Каждое нажатие задаёт скорость вверх (`LIFT = -9`)
- Крокодилы едут справа налево со скоростью 4–8
- За каждого уехавшего крокодила — **+1 очко**
- Столкновение с крокодилом → **конец игры**
- Падение на землю → **конец игры**

2. **Build → Build Solution** (Ctrl+Shift+B)
3. **Debug → Start** (F5)

## Известные особенности

- В J# у `Graphics` **нет** свойств `Color` и `Font` — они
  передаются через `SolidBrush` и `DrawString`
- `new Color(r,g,b)` не работает — нужно `Color.FromArgb(r,g,b)`
- Гравитация должна быть `double`, иначе `0.5` округлится до `0`
  и бегемот перестанет падать
- Generics в J# ограничены — используется `ArrayList` + приведение
